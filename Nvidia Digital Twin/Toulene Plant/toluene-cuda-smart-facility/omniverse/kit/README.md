# Omniverse Kit launch profiles (Blackwell / Linux)

Kit is installed via Omniverse Launcher. These paths are auto-detected by `scripts/blackwell/launch-kit.sh`.

## Environment

```bash
export TKOW_PROJECT_ROOT="$HOME/toluene-cuda-smart-facility"
export TKOW_KIT_PATH="$HOME/.local/share/ov/pkg/kit-<version>/kit"
```

## Launch commands

```bash
./scripts/blackwell/launch-kit.sh              # open Site.usd
./scripts/blackwell/launch-kit.sh --refresh    # open + apply twin_state
./scripts/blackwell/install-extension.sh       # auto-poll twin_state every 2s
```

## Master scene

plant/usd/Site.usd
